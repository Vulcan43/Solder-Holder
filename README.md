# Why I Made It 
I made this because I always have my solder rolling around or on one of those cheap holders that are so light that they fall or break. So I made this so for other people that need a solder older they can 3D print it for cheaper. THis holds your Solder, Soldering Iron and Soldering Iron cleaner.
# Solder-Holder
A 3D printable solder Holder for when you Need some free hands.
